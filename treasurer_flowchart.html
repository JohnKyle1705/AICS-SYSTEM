Municipal Treasurer Flowchart Node Cross-Reference

Node ID Type Branch / Category Condition / Decision Logic Operational Action & Database Effect
Start Entry Point Authentication profiles.role === 'treasurer' && is_active === true Sign in via web portal, grant access to Treasury Dashboard (/treasurer).
Decision 1 Evaluation Disbursement Queue Document/Amount Discrepancy Found in Approved Request? Cross-reference beneficiary ID, intake assessment, and approved grant amount.
Step 1 Process Disbursement Queue Triggered if Decision 1 = YES Return to Admin with written remarks. Request status updated, admin alerted.
Decision 2 Evaluation Fund Liquidity Is funds.current_balance >= amount_approved? Validate municipal category cash reserves before creating financial commitment.
Decision 3 Evaluation Voucher Processing Is Disbursement Voucher (DV) already processed? Checks whether release_status === 'Ready for Release'.
Decision 4 Evaluation Fund Replenishment Can emergency reallocation or subsidy be requested? Trigger budget request to Local Chief Executive / MSWDO.
Step 2 Process Liquidity Alert Triggered if Decision 4 = YES Hold in Queue & send automated low-balance replenishment notification.
Step 3 Process Voucher Preparation Triggered if Decision 3 = NO Process Voucher (DV): Assign DV#, payment method, officer. Status: Ready for Release.
Step 4 Process Official Release Triggered if Decision 3 = YES Confirm Official Release: Disburse cash/check, deduct funds.current_balance, record payouts & fund_transactions. Status: Released.
Decision a Evaluation Treasury Oversight Is task for Fund Allocation or Replenishment? Diverges between capital appropriation and ledger/report review.
Decision b Evaluation Appropriation Type Is it a New Municipal Appropriation / Subsidies? Differentiates between initial budget deposits and corrective reversals.
Step a Process Allocation Form Triggered if Decision b = YES Open Replenishment Modal, enter Ordinance/Reference No., Target Fund & Amount.
Step c Process Ledger Credit Flows directly from Step a Atomic credit to funds.current_balance and funds.total_allocated; logs Allocation transaction.
Decision d Evaluation Audit Correction Is it an Authorized Ledger Reversal / Adjustment? Verify justification for erroneous release or check cancellation.
Step d Process Ledger Adjustment Triggered if Decision d = YES Reverse Transaction: Restore deducted fund balance, revert request to Approved, purge payout row.
Decision c Evaluation Ledger Review Is task for Financial Ledger Audit & Reconciliation? Review historical double-entry logs vs. regulatory liquidation reporting.
Step b Process Ledger Filtering Triggered if Decision c = YES Filter real-time ledger by date, assistance category, reference, or disburser.
Step e Process Financial Audit Flows from Step b & Decision e (YES) Audit double-entry ledger entries, disburser signatures, and barangay totals.
Decision e Evaluation Reporting Format Generate Comprehensive Disbursement & Liquidation Report? Review totals before final export to COA/DSWD official files.
Step f Process Regulatory Export Triggered if Decision e = NO Export formal Statement of Disbursements to Excel (.xlsx) or Municipal Letterhead PDF.
